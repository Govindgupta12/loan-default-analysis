# Loan Default Analysis

This project focuses on analyzing loan data to understand customer behavior, loan distribution, and financial risk patterns using Power BI.

The analysis includes data transformation, DAX calculations, and interactive visual reports to study loan trends, default rates, credit score categories, and customer demographics.

---

## Tools Used

- Power BI
- Power Query
- DAX
- Excel / CSV

---

## Analysis Included

### Loan Overview
- Loan amount by purpose
- Average income by employment type
- Default rate analysis
- Loan trends by year
- Average loan amount by age group

### Applicant Demographics & Financial Profile
- Credit score category analysis
- Loan amount by marital status
- Mortgage and dependent analysis
- Education-wise loan distribution

### Financial Risk Metrics
- YOY loan amount change
- YOY default loan change
- YTD loan analysis
- Financial risk breakdown

---

## Concepts Used

- DAX Measures
- YOY & YTD calculations
- Data validation
- Interactive slicers and filters
- Decomposition Tree
- Sankey Visual
- Power Query transformations
